# 青云云易捷 CloudExpress · 技术架构与特性总览

> **定位**：专为中小规模算力打造的轻量化私有云产品，基于 AI Infra 3.0 多元算力底座，VM+K8s 双栈融合，v6.0。
> **官网**：https://www.qingcloud.com/products/cloudexpress/

## 一、产品定位

| 维度 | 说明 |
|------|------|
| **产品形态** | 超融合一体化软件平台，3 节点起步，横向线性扩展至数百节点 |
| **核心架构** | AI Infra 3.0 多元算力底座，全栈自研 |
| **负载类型** | VM 虚拟机 + 容器（K8s/KubeSphere）+ AI 推理（GPU/NPU）三栈融合 |
| **信创支持** | 信创云易捷：鲲鹏 920 / 飞腾 S2500，Kylin / UOS / OpenEuler |
| **当前版本** | v6.0（2025-12-31 发布） |

## 二、技术架构 · 六层模型

### 1. 用户与接入层
- 🌐 **Web 管理控制台** — 可视化全功能管理
- 📱 **CLI / SDK / API** — 开发运维自动化入口
- 🔐 **统一身份认证 (IAM)** — 单点登录、RBAC 权限
- 📊 **可视化监控大屏** — 实时容量/性能/告警
- 📋 **多租户 / 工单审批** — 企业级运营管控
- 🔗 **北向对接** — CMDB / BOSS / ITSM 集成

### 2. 云管理平台层
- 📦 **资源编排 (Orchestration)** — 模板化一键部署
- 📐 **计量计费 (Metering)** — CPU/内存/存储/GPU 多维度
- 🔔 **告警 & 事件中心** — 自定义阈值 + 自动通知
- 📈 **容量规划 & 趋势分析** — AI 辅助预测
- 📋 **运维自动化 (AutoOps)** — 巡检/备份/快照策略
- 📜 **操作审计 (Audit Log)** — 全链路合规追溯

### 3. 计算服务层（三栈融合 · 核心差异化）
| 栈 | 技术基础 | 关键能力 |
|----|----------|----------|
| 🖥 **VM 虚拟机** | KVM/QEMU/Libvirt | vCPU 热添加、内存热添加、在线热迁移、HA 自动恢复 |
| 📦 **容器** | KubeSphere / K8s | Pod 调度管理、Harbor 镜像仓库、DevOps CI/CD |
| 🤖 **AI 推理** | GPU/NPU 异构调度 | GPU/NPU 纳管、模型推理服务、vGPU / MIG 切分 |

> **混合调度价值**：CPU/GPU 异构资源统一调度，GPU 闲时分配给容器，CPU 高峰弹性调度；VM/容器/AI 推理负载的资源隔离与优先级抢占。

### 4. 平台调度与虚拟化层
- ⚙ **统一资源调度引擎** — VM 调度 + Pod 调度 + AI 推理调度一体化
- 🔧 **核心虚拟化组件** — KVM / QEMU / Libvirt / **SPDK vhost**（自研存储加速）
- 🌐 **软件定义网络 (SDN)** — OVS / VXLAN 隧道、安全组、浮动 IP、负载均衡
- 🖥 **Host OS 不绑定** — CentOS / Rocky / Kylin / UOS / OpenEuler 全兼容

### 5. 存储服务层
- 💾 **分布式块存储** — Ceph / QingStor
- 🗄 **对象存储** — S3 兼容
- 📸 **快照 / 克隆 / 备份** — 秒级快照，增量克隆
- 🔁 **多副本 ×3 + 纠删码** — 数据高可靠
- ⚡ **SSD 缓存加速池** — NVMe SSD 缓存层
- 📀 **HDD 容量层** — NVMe/SSD/HDD 混合存储分层

### 6. 基础设施层（不绑定硬件）
| 架构 | 典型配置 | 网络 |
|------|----------|------|
| 🖥 **X86** | 2×Xeon Gold 6430 (64C/128T) · 512GB DDR5 · 4×3.84TB NVMe · 8×16TB HDD | 6×25G NIC bond |
| 🖥 **信创 ARM** | 2×鲲鹏 920 64C / 2×飞腾 S2500 64C · 512GB DDR4 · 4×3.84TB NVMe · 8×16TB HDD | 6×25G NIC bond |

## 三、三平面物理隔离网络

| 平面 | 带宽 | 用途 |
|------|------|------|
| 🔧 **管理网络** | 万兆 | 集群管理 · API 通信 · 监控 · 元数据同步 · 心跳 |
| 🌐 **业务网络** | 万兆/25G | VM 对外通信 · 负载均衡 VIP · VXLAN 隧道 · 浮动 IP |
| 💾 **存储网络** | 万兆/25G | 分布式副本同步 · iSCSI · 数据迁移 · 快照传输 |

> 核心交换层支持堆叠/MLAG，实现高可用；外部经防火墙/NAT 接入。

## 四、最小部署拓扑（3 节点 · 超融合一体化）

```
节点 1 (Master)    节点 2 (Follower)   节点 N (可扩展)
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 控制平面     │  │ 控制平面     │  │ 控制平面     │
│ 计算 (KVM)   │  │ 计算 (KVM)   │  │ 计算 (KVM)   │
│ 存储 (Ceph)  │  │ 存储 (Ceph)  │  │ 存储 (Ceph)  │
│ 网络 (OVS)   │  │ 网络 (OVS)   │  │ 网络 (OVS)   │
└──────────────┘  └──────────────┘  └──────────────┘
      ↕ 三平面物理隔离交换机 ↕
```

- 每节点承载：管理 + 计算 + 存储 + 网络，全融合
- 分布式存储三副本写入，数据跨节点同步
- 从 3 节点起步，在线横向扩展

## 五、v6.0 核心新增能力

1. **AI 推理深度融合** — VM + 容器 + AI 推理统一平台，GPU/NPU 异构调度
2. **自研 SPDK vhost 调度器** — 大幅提升存储调度性能
3. **VM/Pod/AI 全域资源统一调度** — 优先级抢占，资源隔离
4. **全生态开放兼容** — 不绑 Host OS、不绑存储、不绑硬件
5. **边缘场景适配** — 零售门店、工业产线、边缘基站一体化部署
6. **计量计费精细化** — 多维度计费模型
