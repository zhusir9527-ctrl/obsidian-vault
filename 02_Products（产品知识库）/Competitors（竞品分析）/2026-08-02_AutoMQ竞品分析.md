# AutoMQ 竞品分析

## 一句话定位
做"云原生 Kafka"的基础软件创业公司——把 Kafka 的存储层从本地磁盘搬到 S3/对象存储，主打成本降低 60-75%、秒级弹性扩缩容、100% Kafka 协议兼容。口号：Diskless Kafka on S3（无盘 Kafka）。

## 产品与技术（核心卖点）
- **AutoMQ for Kafka**：保留 Kafka 全部核心协议，只重写存储层（S3 为主存储 + 低延迟 WAL + 内存缓存）
- 卖点：P99 延迟 <10ms / 无限存储 / 秒级伸缩 / 零跨 AZ 流量费 / 零磁盘运维
- 衍生能力：Table Topic（topic 自动转 Iceberg/Delta 湖表，免 ETL）、AutoMQ Linking（任意 Kafka 零停机迁移）、多集群容灾
- 合规：SOC 2、GDPR

## 商业模式与定价
- 交付形态：BYOC（自带云部署）+ 纯 SaaS 双轨；云上支持 AWS/GCP/Azure/Oracle，国内有腾讯云合作
- 计费模型（按量分成式，非传统 License）：
  - 数据写入 $0.008-0.02/GiB、读取 $0.00275-0.0067/GiB、留存 $0.005-0.01/GiB/月
  - 集群在线时长 $0.411/小时（Pro 约 $300/月固定）
  - 基础设施费直接付给云厂商，AutoMQ 只收托管服务费
- 官方宣称节省：vs Apache Kafka 67%、Confluent 75%、MSK Standard 66%、MSK Serverless 62%、Kinesis 57%
- 示例：20 MiB/s 写入规模，AutoMQ 月费 $1,664 vs 自建 Kafka $5,098

## 客户与市场验证
- 官网列示 100+ 企业客户：LG U+、Grab、腾讯、得物、本田、吉利、京东、爱奇艺、腾讯音乐、HubSpot 等
- 生产环境 300+ GiB/s 吞吐
- AWS Differentiated Partner + 腾讯云合作伙伴
- 主攻海外（AWS/GCP 生态）明显比国内激进，国内借腾讯云渠道

## 风险与观察点
- 技术路线依赖对象存储（S3 生态），国内私有云/信创环境适配是短板——恰是国产云的机会点
- 收入模式高度绑定公有云厂商分成，与 AWS/腾讯云既是渠道又是竞对（云厂商自家都有 MQ 产品）
- 天使轮后未见大规模后续融资公开报道，商业化仍在爬坡期
- 竞对：Confluent（已上市）、云厂商原生 MQ（MSK/RocketMQ）、开源 Kafka 自建阵营

## 对我方（青云）相关性判断
1. 情报扫描：值得长期跟踪的国产基础软件新势力，技术路线（存储计算分离+对象存储）是行业共识方向，团队国内第一梯队
2. 合作/生态：纯公有云路线，与青云私有云/行业云场景不直接冲突；可能作为"国产 Kafka 平替"出现在客户 MQ 选型中——客户问"Kafka 太贵怎么办"时是重要对标项
3. 竞品威胁：青云无消息中间件产品线则威胁不大，更多是生态参考；若有相关产品线需重点关注
