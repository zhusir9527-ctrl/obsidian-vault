# AI 产出归档规则

> 目的：让 Codex 等 AI 助手产出的文档自动进入 Obsidian 知识库，形成沉淀，便于检索复用。

## 归档位置（按内容类型）

| 产出类型 | 归档目录 |
|---------|---------|
| 产品资料 / 报价模板 / 竞品 | `02_Products（产品知识库）/对应厂商/` |
| 客户画像 / 商机 / 项目跟踪 | `03_Customers（客户知识库）/对应行业/` |
| 投标 / 标书 / 方案 | `04_Bids（投标项目库）/` 或 `05_Solutions（解决方案库）/` |
| 会议纪要 / 日报 / 复盘 | `09_DailyNotes（日记与复盘）/` |
| 通用资料 / 参考 | `10_Resources（资源中心）/` |
| 未分类暂存 | `00_Inbox（收件箱）/` |

## 命名规范

- 笔记：`YYYY-MM-DD_标题.md`（如 `2026-08-21_青云智算平台报价体系与模板归档.md`）
- 附件（Excel/PPT/PDF/图片）：放入对应目录的 `attachments/` 子目录，保留原文件名
- Frontmatter 至少包含：`date`、`tags`、`category`、`source`

## 归档动作清单

1. 产出成品文件 → 复制到对应 `attachments/`
2. 创建索引笔记，用 `[[attachments/文件名\|显示名]]` 链接附件
3. 笔记内沉淀关键信息（价格表、结论、来源链接），不只有文件链接
4. 更新对应目录的 README / 知识库索引页
5. 带数据来源（Confluence 页面链接、URL 等）

## 使用工具

- 优先使用 Obsidian MCP 工具（`obsidian-mcp`）；若 MCP 不可用，直接按上述规则写入库目录（Obsidian 会自动识别）。
