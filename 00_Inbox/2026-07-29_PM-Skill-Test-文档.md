# 项目章程: 客户门户V3.0重构

**目标**: 3个月内完成Vue3重构，移动端适配，NPS从32提升至55+。
**范围**: 
- 交付：前台门户、个人中心、工单系统、消息中心
- 不含：后台管理系统、BI报表、第三方集成
**成功标准**: 
- 移动端Lighthouse评分≥90
- 页面加载<2秒
- 客户投诉降至月均≤3起

# 开发任务分解

## 规格摘要
**技术栈**: Vue3 + Vite + Pinia + Element Plus + TypeScript
**API**: RESTful，现有后端接口不变
**时间**: 12周（2026-08-04 ~ 2026-10-30）

## Sprint 1 — 基础设施 (8月4日-8月15日)

### [ ] Task 1: 项目脚手架搭建
**描述**: Vite + Vue3 + TypeScript 初始化，ESLint/Prettier配置，Git Hooks
**验收标准**: 
- [ ] `npm run dev` 正常启动
- [ ] ESLint 0 error
- [ ] Husky pre-commit hook 生效
**文件**: `package.json`, `vite.config.ts`, `.eslintrc.cjs`

### [ ] Task 2: 路由与布局框架
**描述**: Vue Router配置，Header/Sidebar/Footer布局组件，响应式断点
**验收标准**:
- [ ] 5个顶级路由可访问
- [ ] 移动端侧边栏折叠
- [ ] 面包屑导航正确
**组件**: Element Plus Layout, Vue Router

## Sprint 2 — 前台门户 (8月18日-9月5日)

### [ ] Task 3: 首页+产品展示
**描述**: 首页Banner、产品卡片列表、搜索筛选
**验收标准**:
- [ ] 产品列表分页加载
- [ ] 搜索200ms内响应
- [ ] 移动端卡片自适应2列
**文件**: `src/views/home/`, `src/components/product/`

### [ ] Task 4: 登录注册
**描述**: 手机验证码登录、微信扫码登录、Token管理
**验收标准**:
- [ ] 验证码60秒倒计时
- [ ] Token自动刷新
- [ ] 登录态持久化
**参考**: 规格书 §3.2

## Sprint 3 — 工单+消息 (9月8日-9月26日)

### [ ] Task 5: 工单系统
**描述**: 创建工单、工单列表、状态流转、附件上传
**验收标准**:
- [ ] 工单CRUD完整
- [ ] 状态流转: 待处理→处理中→已完成→已关闭
- [ ] 附件≤10MB上传
**文件**: `src/views/ticket/`

### [ ] Task 6: 消息中心
