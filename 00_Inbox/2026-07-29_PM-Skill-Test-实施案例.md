# 实施任务分解（WBS）

## 阶段1: 基础环境部署（8月3日-8月15日，12天）

### [ ] T1.1 现场勘验与环境确认
**描述**: 到客户现场确认机房环境（电力、散热、网络），签署现场勘验报告
**验收标准**:
- [ ] 机柜空间确认（20节点，需8个标准柜）
- [ ] 电力负载确认（额定功率≥40KW）
- [ ] 网络拓扑确认（管理网+业务网+存储网三网隔离）
- [ ] 堡垒机/跳板机就绪
**工时**: 2人天 | **参考**: 合同附件A-技术方案

### [ ] T1.2 K8s集群部署
**描述**: 基于KubeSphere部署K8s集群，包括master节点（3台）高可用配置、worker节点（17台）纳管
**验收标准**:
- [ ] kubectl get nodes 全部Ready
- [ ] etcd集群3节点正常
- [ ] CoreDNS正常解析
- [ ] Calico网络插件就绪，跨节点Pod互通
**工时**: 4人天 | **风险**: R2

### [ ] T1.3 GPU驱动与插件安装
**描述**: NVIDIA Driver 535 + CUDA 12.2 + NVIDIA Device Plugin + GPU Operator
**验收标准**:
- [ ] nvidia-smi 可识别全部20节点GPU
- [ ] `kubectl describe node` 显示GPU资源
- [ ] GPU共享测试（MIG配置确认）
**工时**: 3人天 | **风险**: R2

### [ ] T1.4 存储与镜像仓库
**描述**: 部署分布式存储（客户自有Ceph集群对接）+ Harbor私有镜像仓库
**验收标准**:
- [ ] PVC动态创建成功
- [ ] Harbor推送/拉取镜像正常
- [ ] 青云平台镜像导入Harbor
**工时**: 3人天
