# 目标客户清单与触达追踪 V1.0

> 用途：系统化拓新客，告别"触达靠偶遇"
> 更新频率：每周一规划日更新一次
> 原则：存量客户维护时间压到30%，70%时间用于拓新

---

## 快速使用指南

1. **周一规划日**：看「待触达」列，选本周 3 个优先级最高的客户动手
2. **每日情报扫描后**：有新信号立即在对应客户下追加触达记录
3. **每周复盘**：统计「本周新触达」「本周推进」「本周丢单」三个数

## 三、触达记录模板

每次触达后，在对应客户条目下追加：

```markdown
### YYYY-MM-DD | 触达方式 | 联系人

- **方式**：电话/微信/邮件/拜访/会议/渠道引荐
- **对方角色**：CIO/CTO/IT总监/采购/其他
- **关键信息**：
  - 当前技术栈/痛点：
  - 预算/时间窗口：
  - 决策链：
- **我方动作**：发送了xx材料 / 约了下一次会议 / 等待反馈
- **下一步**：YYYY-MM-DD 前做 xx
- **状态**：🟢 推进中 / 🟡 等待对方 / 🔴 已丢 / ⚪ 观望
```

## 五、情报信号 → 行动转化规则

当每日情报扫描发现以下信号时，自动触发行动：

| 信号类型 | 关键词 | 行动 |
|----------|--------|------|
| 扩产/建厂 | "新工厂" "扩产" "生产基地" | → 立即查企业画像，生成一页纸，3天内触达 |
| 数字化招标 | "招标" "云平台" "容器" "AI平台" | → 当天看标书，判断是否匹配，24h内响应 |
| 智能制造 | "智能制造" "工业互联网" "灯塔工厂" | → 准备云原生+AI智算方案简介，周内触达 |
| 融资/上市 | "IPO" "融资" "Pre-IPO" | → 记录，待资金到位后跟进 |
| 领导考察/合作 | "战略合作" "签约" "揭牌" | → 判断是否和青云产品相关，关联触达 |
| 信创替换 | "信创" "国产化" "去IOE" "替换VMware" | → 最高优先级，当天触达 |
