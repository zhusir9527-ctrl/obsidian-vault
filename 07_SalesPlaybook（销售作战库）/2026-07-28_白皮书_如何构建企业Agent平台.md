# 如何构建企业Agent平台

> 从ChatBot到自主Agent的进化之路

## 文件

- [白皮书_如何构建企业Agent平台.docx](file:///Users/zhu/Desktop/白皮书_如何构建企业Agent平台.docx)

## 核心要点

1. **Agent vs ChatBot**：从"我问你答"到"我说你做"，自主理解→拆解→调用工具→执行
2. **五层架构**：接入层 → Agent编排层 → 能力层(LLM/RAG/FunctionCall) → 数据层 → 基础设施
3. **三大核心**：智能体编排引擎（单/链式/群组）、工具调用框架（Function Calling）、记忆系统（短/长/共享）
4. **三步构建**：基础能力(1-2月) → 场景扩展(3-6月) → 平台运营(6-12月)
5. **制造5场景**：排产助手、质量异常、设备诊断、供应商谈判、客户需求分析

## 适用场景

客户已部署大模型，想升级到Agent自动化业务时使用
