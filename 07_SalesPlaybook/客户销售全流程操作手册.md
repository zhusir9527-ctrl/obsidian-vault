## 流程速览

```
拓客发现 → 情报采集 → 触达建联 → 需求挖掘 → 方案设计 → 报价商务 → 异议处理 → 谈判关单 → 交付启动 → 持续经营
```

## 10 阶段索引

| 阶段 | 核心目标 | 关键技能 |
|------|---------|---------|
| 1.拓客发现 | 找到理想客户 | ICP匹配/触发事件/社交销售 |
| 2.情报采集 | 深度理解客户 | 五路并行搜索/决策链分析 |
| 3.触达建联 | 成功建立联系 | 冷外联/多轮跟进/AB测试 |
| 4.需求挖掘 | 精准定位痛点 | SPIN提问/预算提取/共情 |
| 5.方案设计 | 赢得技术信任 | 7页黄金结构/竞品定位 |
| 6.报价商务 | 准确报价不丢单 | 定价查询/折扣策略 |
| 7.异议处理 | 化解客户担忧 | LAER模型/竞品应对 |
| 8.谈判关单 | 签署合同 | 购买信号/紧迫感/渐进承诺 |
| 9.交付启动 | 顺利启动项目 | 客户登船/KPI基线 |
| 10.持续经营 | 实现增购续约 | 增购/转介绍/健康度监控 |

## 五大运营原则

1. **先情报后行动** — 任何客户接触前，先跑五路并行搜索
2. **三件套并行** — 拜访准备一次输出：方案正文 + 演讲脚本 + 拜访指南
3. **7页黄金结构** — 封面→挑战→架构→场景→差异→风险→下一步
4. **Confluence为事实源** — 定价/产品参数一律从Confluence查
5. **六段式客户档案** — 画像/需求/切入点/价值/竞品/话术

## 关键规则速查

- **报价三不**：不第一个报价 / 不报最低价 / 不免费送核心产品
- **竞品应对三不**：不贬低竞品 / 不回避问题 / 不自说自话
- **时间规则**：上午9-11:30深度块 / 每天只盯一个主任务 / 15:30后不做决策
