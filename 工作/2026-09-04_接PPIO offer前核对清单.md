## 二、接 offer 前逐项核对清单

### 2.1 青云资金链：是"消息"还是"已发生"？
- [ ] 本月工资是否按时代发（有无推迟先例）
- [ ] 社保 / 公积金是否按时足额缴纳（可查杭州参保记录）
- [ ] 供应商 / 渠道款有无拖欠迹象
- [ ] HC 是否冻结、有无非正常离职潮
- [ ] 内部对年底的正式口径 / 财报复盘信息
> 判定：出现任一如"缓缴/晚发/冻结"实锤 → 不必等 PPIO 流程走完，尽快落定走人。

### 2.2 PPIO offer 白纸黑字
- [ ] 20,000 是转正后还是试用期即同额；试用期时长与打折规则
- [ ] 公积金基数确认按 20,000（"实际缴纳"写入 offer）
- [ ] 绩效/提成结构：base:提成比例、考核口径（token 量?回款?）
- [ ] 期权：归属期、行权价、回购条款、离职带走规则——**不算进饭钱**
- [ ] 竞业限制条款：入职文件与青云合同是否冲突
- [ ] 出差/报销政策（杭州-上海往返频次、常驻口径）

### 2.3 居住与通勤安排（问 HR 的三句话）
- [ ] "社保在上海，客户在杭州——我能否杭州居住、上海入职？"
- [ ] "常驻口径是上海打卡还是杭州办公？杭州往返与住宿谁承担？"
- [ ] "派驻/出差补贴标准？"

### 2.4 竞业与离职合规
- [ ] 查青云劳动合同竞业条款（离职补偿、期限、地域）
- [ ] 确认无保密/竞业启动风险后再签 PPIO
- [ ] 交接清单：华孚 / 顾家 / 甬江 / 宁大 / 浙江制造业在跟客户 → 书面交接留口碑

### 2.5 社保与公积金衔接
- [ ] 杭州→上海社保转移时间与中断影响（医保/公积金/买房资格）
- [ ] 青云试用期公积金是否到账；离职当月结算
- [ ] 若未来回杭州，上海公积金可转移/提取政策

- PPIO 卖的是 **token 量与价格战**，买家是互联网/大模型公司；自己真正的差异化 = **私有化 + 智算运营分成 + 制造/政企纵深**（KubeSphere、异构 GPU 全栈、Token 运营系统）。两者不同路。
